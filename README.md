# 原型审查与打磨

面向 Web、移动端和业务系统的 UI 原型制作、审查与精修技能。覆盖视觉层级、跨页一致性、图表、素材、动效与关键交互，区分只读审查和已授权的修改。

## 安装

在支持 Agent Skills 的工具中，将本仓库安装为 `prototype-craft-review` 技能。例如在 Codex 中将仓库地址交给助手安装，或使用兼容的技能安装工具。

## 使用

告诉助手原型的位置和任务，例如：审查已有原型，或在保持现有结构的前提下打磨视觉和交互。技能会按需读取 `references/` 中的对应说明。

整体视觉精修可按需使用 `design-taste`；需要生成或编辑位图时可使用 `imagegen`。这些是可选的外部能力，需在使用环境中另行提供。`evals/` 包含技能行为的示例检查用例。

公开版本对一处项目案例做了通用化处理。
