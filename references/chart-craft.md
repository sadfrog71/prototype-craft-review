# 分析图表：表达与绘制精修

用于图表主导的分析页面，或用户认为图表普通、单调、缺少表现力时。单张图定向修改只处理相关项；整组图先做好代表图，再推广。图表引擎、数据口径、绘制完成度与用户认可分别核对。

## 先判断图表承担的任务

- 明确用户要发现趋势、比较差异、理解结构、定位异常还是追查关系，确定第一眼应看到的重点。同一数据可有不同表达，不能为增加图种而换图。
- 核对当前数据规模与量级。序列量级相差很大时，小序列可能被压平；可按问题拆分趋势、使用明确基准的相对变化或小多图，不随意用双轴放大变化。少量记录、单一类别或全零值不必占一个大圆环。
- 区分业务操作、日常分析、汇报叙事与展示大屏；根据受众和使用频次决定密度、材质与动态强度，保持项目已确认主题。

## 把参考落实到绘制

优先看项目已有主题、组件与参考，再找同场景的具体官方示例。说明借鉴的是绘图区比例、线面关系、标签、配色、标注还是交互；只说“参考字节/ECharts”不足以形成设计。

- [VChart 示例](https://www.visactor.io/vchart/example)：按实际分析问题寻找图形、布局、标注及叙事参考。
- [Semi 图表设计系统](https://semi.design/dsm_vchart/doc/en-US/introduction/start)：参考全局与元素级的主题定制。
- [ECharts 富文本标签](https://echarts.apache.org/handbook/en/how-to/label/rich-text/)：参考数值、单位、名称的分层排版。

已有引擎能实现目标时优先精修，不因为示例好看就迁移依赖。普通坐标图、指标和交互用图表/代码真实绘制；ImageGen 可用于必要场景配图，不能把需要筛选和下钻的图表画成位图。

## 建立主题，同时逐图定标

复用项目现有样式和图表配置，先统一字体、数值精度、单位、分类色、状态色、图例、提示框和交互状态；再根据图形、数据量和容器调整。不要把一份固定高度、小字号和统一配色配置机械套给所有图。

| 绘制环节 | 具体判断 |
| --- | --- |
| 构图 | 让关键图、辅助图和明细形成主次；绘图区、标题、图例、说明按信息量分配空间，避免图很小而卡片很大 |
| 视觉重点 | 主系列、辅助系列、选中项、异常点有清晰权重；可以通过颜色、线宽、透明度和局部标注建立层级，无需给每个系列同等强调 |
| 线、柱与面积 | 按实际尺寸确定线宽、柱宽、间隔、圆角和面积填充；数据密集时控制点符号数量，平滑处理不能改变业务含义 |
| 坐标与网格 | 刻度、零基线、单位和范围清楚；弱化辅助线但保留比较依据，避免为了放大画面效果隐瞒截断或缩小范围 |
| 标签 | 根据空间选择直接标签、端点、重点数值和提示框；数字与单位分层且对齐，小区域不硬塞文字，标签缺失和冲突都需处理 |
| 色彩与材质 | 品牌/操作色、分类色、状态色各有职责；分类可丰富且跨图含义一致。渐变、光泽或深色效果应适合场景并帮助层级，不能扭曲面积、长度或色阶表达 |
| 注释 | 峰谷、阈值、贡献和比较结果可由当前数据计算并标注；事件和原因需有来源，不给每张图强加一句泛化结论 |

表现力也来自图形组合。例如主趋势与分项趋势、排序与目标参照、结构占比与贡献明细可以共同回答问题；不靠重复环图、堆叠图种或填满卡片制造丰富度。

## 业务与数据约束

- 标明统计范围、时间与单位；指标、图表、筛选和下钻明细来自同一数据范围。比较说明基线，当前状态分布不冒充历史转化率。
- 矩阵混合等级、数量和状态时，各维度保持独立含义，不用同一连续色阶暗示相同量纲或未定义的综合评分。
- 真实数据保持原样。演示样本应有合理业务结构并标明演示；重复机械曲线可能暴露测试数据问题，但不能为漂亮曲线凭空补波动。
- 正常、空结果、全零、少量记录、极端值和长标签，按当前任务可能出现的状态检查，不用样本边界扩成完整数据平台。

## 动态与交互的完成度

入场按信息阅读顺序呈现；筛选更新保留位置与对象关系；悬浮、选中、图例和下钻有连贯反馈。按数据密度和用途决定是否需要缩放、联动或叙事动画，不给每张小图增加控件。

提示框中名称、数值、单位清楚对齐，颜色与系列对应，定位不遮挡关键内容。动效实播检查节奏、停止与减少动态偏好；按钮微动、统计滚动和叙事演示不共用一个机械时长。

## 代表图与复核

针对主要图形选代表样例，在真实容器、同一组数据和同一视口下对照原版与参考，复看首版后修正，再应用到其余模块。小修改不要求全套样板，不重复索取已授权的小样批准。

视觉复核要能具体说明：重点是否一眼可见、图形比例是否合适、标签在原尺寸是否易读、辅助信息是否克制、相邻图是否有主次、筛选与悬浮是否顺畅。修复标签碰撞、裁切、模糊和重复感；“更酷炫”或“换了库”不作为证据。

分别记录：技术运行、业务口径、视觉判断和用户反馈。自动检查或交互通过不能直接标记“图表已精修”；用户没有确认时不声称已通过其审美验收。
